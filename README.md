# 🍽️ Система бронирования столиков в ресторане

Проект представляет собой веб-приложение для бронирования столиков в ресторане с возможностью управления бронированиями для администраторов и пользователей.

## 🚀 Основные возможности

- **Пользователи:**
  - Просмотр доступных столиков
  - Бронирование столиков на выбранную дату и время
  - Просмотр и редактирование своих бронирований
  - Отмена бронирований

- **Администраторы:**
  - Управление столиками (добавление, редактирование, деактивация)
  - Просмотр всех бронирований
  - Подтверждение бронирований

## 🛠 Технологический стек

- **Backend:**
  - Python 3.10+
  - Django 4.2
  - Django REST Framework
  - PostgreSQL
  - Redis (для Celery)

- **Frontend:**
  - HTML5, CSS3
  - Bootstrap 5
  - JavaScript (базовый)

- **Инфраструктура:**
  - Docker
  - Docker Compose
  - Nginx (опционально)
